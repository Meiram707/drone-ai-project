Этап 2. Генерация траектории

Система рассчитывает маршрут облёта пшеничного поля в Акмолинской области — таким образом, чтобы покрыть нужную площадь с минимальным расходом заряда и облететь препятствия.

Типы траекторий

  • Круговая — облёт по окружности вокруг заданной точки, удобна для точечного осмотра одного участка.
  • Восьмеричная — фигура «восьмёрка», позволяет осмотреть два соседних участка за один проход.
  • Произвольная — маршрут, подстроенный под форму конкретного поля и расположение препятствий.

Выполняемые задачи

  • Применение алгоритмов ИИ для выбора формы маршрута под задачу.
  • Учёт препятствий — опор ЛЭП, построек, лесополос на границе поля.
  • Определение оптимального пути по критерию «покрытие площади / время полёта».

Конкретный район

В качестве примера взят участок пшеничного поля в Акмолинской области. Он имеет вытянутую прямоугольную форму, поэтому для полного прохода выбирается произвольная траектория по параллельным галсам, а для точечной проверки подозрительных зон — круговая.
