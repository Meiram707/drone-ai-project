# Проектирование интеллектуальных систем управления

Веб-приложение из 7 страниц, описывающее систему интеллектуального
управления БПЛА при мониторинге пшеничного поля (Акмолинская область).
Этап 7 содержит рабочий калькулятор NDVI на JavaScript.

## Структура проекта

```
drone-ai-project/
├── index.html        главная страница: интро, путь из 7 этапов, таблица методов ИИ
├── etap1.html         Подготовка данных и ПО
├── etap2.html         Генерация траектории
├── etap3.html         Управление полётом
├── etap4.html         Обнаружение объектов
├── etap5.html         Построение карты
├── etap6.html         Изменение координат
├── etap7.html         Принятие решений + блок-схема + калькулятор NDVI
├── css/
│   └── style.css      все стили проекта (агро-тема: зелёный/пшеничный золотой)
└── js/
    ├── script.js       подсветка активного этапа в навигации
    └── ndvi.js         логика калькулятора NDVI (подключён только на etap7.html)
```

Никакой сборки (npm, webpack и т.п.) не нужно — это обычный статический
сайт на чистых HTML/CSS/JS, как и было в задании.

## Как открыть проект в VS Code

1. Скачай папку `drone-ai-project` целиком и положи её туда, где
   удобно хранить университетские проекты.
2. В VS Code: **File → Open Folder…** → выбери папку `drone-ai-project`.
   Слева в Explorer должна появиться именно структура выше.
3. Установи расширение **Live Server** (автор Ritwick Dey) — Extensions
   (значок квадратиков слева) → поиск "Live Server" → Install.
4. Открой `index.html`, нажми правой кнопкой по файлу в редакторе →
   **Open with Live Server** (или кнопка "Go Live" внизу справа).
5. Браузер откроется на `http://127.0.0.1:5500/index.html` — сайт
   рабочий, можно кликать по этапам.

Если Live Server ставить не хочешь — можно просто дважды кликнуть по
`index.html` в проводнике, он откроется прямо в браузере как обычный
файл. Разница: Live Server автоматически перезагружает страницу при
сохранении изменений, обычное открытие — нет.

## Как всё устроено

- **Навигация между этапами** — на каждой странице этапа сверху есть
  строка из 7 кружков (степпер). `js/script.js` сам подсвечивает
  текущий этап золотым цветом, глядя на имя открытого файла — вручную
  ничего помечать не нужно.
- **Калькулятор NDVI** (`etap7.html`) — вводишь значения Red и NIR
  (от 0 до 1, это доля отражённого света), жмёшь "Рассчитать NDVI".
  `js/ndvi.js` считает `NDVI = (NIR − Red) / (NIR + Red)`, определяет
  категорию состояния растительности и решение "нужен ли повторный
  снимок" — ровно та логика, что на рисунке 3 задания. Три кнопки
  сверху — готовые тестовые примеры (здоровый участок / умеренный
  стресс / сильный стресс).

## Если захочешь что-то изменить

- Текст каждого этапа — это обычный HTML внутри `<div class="panel">`
  в соответствующем `etapN.html`, его можно редактировать напрямую.
- Цвета и шрифты — переменные `:root` в самом верху `css/style.css`
  (`--field-green`, `--wheat-gold` и т.д.), поменяешь один раз — изменится
  везде.
- Порог, при котором калькулятор решает "нужен доп. снимок" — константа
  `NDVI_THRESHOLD` в начале `js/ndvi.js` (сейчас 0.4).
