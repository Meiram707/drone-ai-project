# Интеллектуальная система управления БПЛА — мониторинг пшеничного поля

Веб-приложение из 7 страниц, демонстрирующее концепцию интеллектуальной
системы управления БПЛА при мониторинге пшеничного поля (Акмолинская
область, Казахстан). На этапе 7 реализован рабочий калькулятор индекса
NDVI на JavaScript.

## Этапы системы

1. Подготовка данных и ПО
2. Генерация траектории
3. Управление полётом
4. Обнаружение объектов (YOLOv8)
5. Построение карты (SLAM)
6. Изменение координат
7. Принятие решений — блок-схема + калькулятор NDVI

## Технологии

HTML5, CSS3, JavaScript (без фреймворков и сборки) — статический сайт,
который можно открыть прямо в браузере.


## Калькулятор NDVI

`NDVI = (NIR − Red) / (NIR + Red)`, где Red и NIR — доля отражённого
света в красном и ближнем инфракрасном диапазоне. По результату
система определяет состояние растительности и решает, нужен ли
повторный снимок участка.
